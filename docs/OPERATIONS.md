# 日常运营指南

## 商品上架

1. 分类管理 → 新建分类。
2. 商品管理 → 新建商品，填写标题、短说明、价格、地区、购买数量限制、商品介绍、购买须知。
3. 每个地区 / 套餐 / 年限分别建商品，库存与价格独立。
4. 卡密库存 → 选择商品 → 粘贴交付内容，每行一份，最多 30 份一次。多次导入自动去重。
5. 勾选商品「上架销售」。可售库存为 0 的商品显示缺货。

卡密可以是兑换码、许可、文字交付内容。所有实际交付内容在数据库中 AES-GCM 加密，后台不会显示完整明文。

## 订单与售后

- 未付款订单保留库存 15 分钟。生成 USDT 支付单后额外保留 10 分钟用于链上确认，付款截止不延长，不能立即取消。过期库存由请求或支付巡检清理。
- USDT 配置完成后，固化到账触发自动交付；[支付接口页面](PAYMENTS.md) 查看异常与补查。需要手工确认时，只有店主核对真实到账后可以确认收款。必须填写唯一流水号和处理依据。
- 确认收款与发货在同一事务完成。库存不足或冲突会回滚，不会留下虚假的已发货状态。
- 客户凭「订单号 + 随机密钥」查询；只有订单号不能获得卡密。忘记密钥时系统不能回显原密钥，因为只保存哈希。
- 客户可以创建售后工单，后台回复会显示在订单页面。
- 已发货的退款只能由店主登记，先完成外部退款。交付内容不会重新变成可售库存。
- 订单列表按 50 条分页，CSV 导出当前筛选条件下的当前页；CSV 对公式前缀进行转义。

## 员工权限

| 角色 | 能做什么 |
| --- | --- |
| 店主 | 全部管理、确认收款、登记退款、站点设置、员工管理、审计日志 |
| 运营 | 商品、分类、库存、查看订单、处理工单、业务概览 |
| 客服 | 查看订单、处理工单、业务概览 |

点击右上角头像修改密码。改密码、停用员工会使相关会话失效。会话有效期为 8 小时。

## 演示与正式环境

体验站默认使用演示环境，可点击「进入演示管理后台」。演示入口不校验商家密码，因此只能在专用演示 Worker 与独立数据库中开启。示例商品有 `is_example` 标记，关闭演示后无法交易；修改示例标题不会自动变成真实商品。

正式环境新建自己的商品，保持 `DEMO_MODE=false`，通过初始化令牌创建店主。不要把演示数据库直接用于正式经营。

## 上线准备

填写自己的商品、客服信息、购买协议、隐私政策与服务约定；接入正式支付后进行小额实单对账。Cloudflare 标准全球 Workers 对中国大陆访问速度需用实际网络测量，不能保证大陆体验。是否使用大陆加速或境内部署，要依据你的经营实体、实际业务和支付商户要求另行确定。
